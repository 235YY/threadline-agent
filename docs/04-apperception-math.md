# 统觉层数学研究 v0.1.2

## 选择性注意、主观经历与策略状态

**状态：** 有限模型 A/B/C 组验证完成；基础数学阶段暂告一段落。  
**性质：** 研究记录，不是完整统觉算法，不是实际主体自主性的证明。  
**项目：** Threadline

## 0. 摘要

本文研究一个有限资源主体如何从连续信息流中选择信息、形成主观经历，并在不依赖统一奖励函数的条件下修改自己的认识与注意力策略。

核心问题不是“怎样设计一个更聪明的注意力评分器”，而是：

> **在一个有限资源、信息不完整、持续变化的环境中，如何构建一个不会预先替主体规定价值判断，却又能够严格约束状态变化的数学系统？**

本文给出：

```text
客观事件 / 候选信息 / 工作台 / 主观状态 的区分
适用性类别与偏序支配
未知、不可比、不适用三种信息状态
三层极大集 M_N ⊆ M_P ⊆ M_R
工作台行动计划与 Defer / Inspect 的时序
主体选择对应 α 与策略状态 S_att
A/B/C 三组有限模型验证
```

本文明确区分：

```text
已经证明的数学性质
依赖额外假设的性质
仅证明表达能力的模型构造
尚未解决的研究问题
```

## 1. 思想背景

### 1.1 事实不等于主观认知

客观事件流记录：

```text
谁在什么时候说了什么
主体做了什么
工具返回了什么
```

这是事实层，追加保存，不等于主体“记得”或“理解了”。

主观认知则是：

```text
她注意到了什么
她如何理解
这件事对她意味着什么
她有什么感受
她准备怎样
```

主观认知允许：

```text
忽略
加工
带情绪
记错
前后矛盾
以后修订
```

因此，不能用“最近 N 条原始消息”冒充主观认知。

### 1.2 一个自我，多条线程

注意力线程是材料视图，不是多个主体。

```text
多个线程 = 多个可切换的观察/材料面
主认知   = 一个连续的主观现场
```

线程负责“看哪里、手头有什么材料”；  
主认知负责“这些如何共同构成我的此刻”。

### 1.3 统觉层

本文把“客观事件如何变成主观认知”这一问题定位为一个独立层：

```text
客观事件
→ 选择性注意
→ 经历构造
→ 主观评价
→ 主观状态变化
```

统觉层不拥有事实库，不执行任务，不自动写长期记忆。  
它只负责“把客观信息变成属于同一个主体的主观经历”。

## 2. 四个内容域与四问

### 2.1 四个内容域

| 域 | 回答的问题 | 内容 |
|---|---|---|
| 自我域 | 我是谁？ | 自我模型、状态、承诺、自传 |
| 关系域 | 这对我/我们意味着什么？ | 意义、威胁、affordance、依恋、归属 |
| 世界域 | 世界是怎样的？ | 他人本身、他者心智、因果、对象属性 |
| 规范/抽象域 | 什么是对的、有效的、美的？ | 价值、公平、逻辑、数学、审美 |

重要限定：

```text
四域是“关于性”的方向，不是四个存储仓库
世界域是“她所理解的世界”，不是客观事件流
规范域是“她所认可的有效性”，不是客观真理
```

同一段经历可以同时横跨四个域。

例如“A 看起来很凶”：

```text
世界域：A 的表情/姿态给我“凶”的印象
关系域：这可能对我构成威胁
自我域：我一向对这种人保持距离
规范域：但我不应该只凭外表判断一个人
```

这不是四条记录，而是一个印象在四个域上的坐标。

### 2.2 四问

四问是评价维度，不是四个固定阶段，也不要求每次全部激活：

```text
相关性：这件事与我有什么关系？
意义：这件事意味着什么？
应对：我能做什么？
自我与规范：这件事与我的价值、身份和承诺有什么关系？
```

四问允许部分执行：

```text
未评价
已评价但不确定
暂定
已认可
```

### 2.3 BCRZ 与 O/R/T/S 的位置

BCRZ 是当前评价状态的语义投影：

```text
B：belief / appraisal
C：concern
R：condition
Z：readiness
```

BCRZ 不是统觉层本身，不是记忆库，不是自我核心。

O/R/T/S 是研究性的操作分类：

```text
O：Observation
R：Relation comparison
T：Transformation
S：Test / Selection
```

它用于分析认知操作，不是已证明的最小认知基，也不要求四个顺序阶段。

## 3. 形式模型 v0.1.2

### 3.1 状态对象

第 n 次认知机会的状态至少包含：

```text
X_n = (H_n, S_n^sem, S_n^att, S_n^op, W_n, Df_n, q_n, B_n)
```

| 符号 | 含义 | 责任 |
|---|---|---|
| H_n | 客观事件历史 | 宿主 |
| S_n^sem | 主体对自身认识、偏好、关切的理解 | 主体 |
| S_n^att | 主体认可并采用的注意力策略 | 主体 |
| S_n^op | 检索优先级、驻留、缓存等操作状态 | 宿主维护，受审计 |
| W_n | 当前工作台驻留材料 | 主体选择，宿主执行 |
| Df_n | 暂缓记录集合 | 主体提案，宿主保存 |
| q_n | 当前任务与焦点 | 主体 |
| B_n | 本轮资源预算向量 | 宿主约束 |

必须区分：

```text
H_n：历史
S_n：主体对历史形成的认识与状态
W_n：本轮实际交付/驻留的材料
```

三者不能合并。

### 3.2 候选与信息边界

```text
U_n ⊇ C_n ⊇ D_n
```

| 集合 | 含义 |
|---|---|
| U_n | 本轮声明的、宿主可访问的信息范围 |
| C_n | 宿主生成的候选集合 |
| D_n | 实际交付到工作环境的材料 |
| A_n / A | 本轮计划设置的工作台集合 |

必须记住：

```text
事件存在 ≠ 进入候选
进入候选 ≠ 交付工作台
交付工作台 ≠ 主体关注
主体关注 ≠ 形成经历
形成经历 ≠ 修改长期状态
```

`U_n` 不是“整个世界”，只是本轮可声明的访问范围。

### 3.3 工作台与行动计划

工作台状态：

```text
W_n = 当前驻留的材料集合
```

计划：

```text
π = (A, Δ)
```

其中：

```text
A ⊆ C_n：本轮结束后的工作台集合
Δ：暂缓记录集合
dom(Δ) ⊆ W_n \ A
```

状态更新：

```text
W_{n+1} = A
Df_{n+1} = Df_n ∪ Δ
```

旧材料去向：

```text
Drop_n = W_n \ (A ∪ dom(Δ))
```

因此：

```text
W_n = (W_n ∩ A) ⊔ dom(Δ) ⊔ Drop_n
```

每份旧材料恰好属于：

```text
保留
暂缓
Drop
```

三者之一。

新材料如果没有进入 A，只是“尚未选择”，不自动算作 Drop。

### 3.4 动作语义

| 操作 | 精确含义 |
|---|---|
| Attend(A) | 设置最终工作台集合 A；要求 A 非空 |
| Keep | 保持当前工作台 A = W_n |
| Clear | 主动清空 A = ∅ |
| Defer(S,r) | 将 S 移出工作台，并建立恢复记录 (S,r) |
| Inspect(q) | 发起一次信息查阅；独立时间操作，不直接修改 W |

`Attend(A)` 的隐式删除是 Drop；`Defer` 的删除保留恢复入口。

`Inspect(q)` 期间：

```text
W 保持不变
查询结果作为新事件/候选
不自动成为已关注或已认可
下一次机会再决定 Attend / Keep / Clear / Defer
```

### 3.5 暂缓记录 Df

```text
Df_n = {(S_j, r_j, source_j, status_j)}
```

状态：

```text
pending
eligible
resolved
cancelled
```

生命周期：

```text
Defer(S,r)：
  W' = W \ S
  Df' = Df ∪ {(S,r,pending)}

宿主可检测条件满足：
  pending → eligible

语义恢复条件：
  由主体判断，宿主不能自行判定

eligible：
  重新进入候选集合，不自动进入工作台

主体重新关注：
  resolved

主体取消：
  cancelled
```

特别不变量：

```text
恢复条件满足 ≠ 自动回到工作台
```

`Clear` 不删除 `Df`。

### 3.6 评价维度与适用性

每个维度 i 对应一个偏序：

```text
(L_i, ≥_i)
```

对方案 x，定义适用性集合：

```text
App(x) = {i | 维度 i 对 x 适用}
```

支配关系：

```text
x ≻_ω y
```

当且仅当：

```text
App(x) = App(y)
所有 i ∈ App(x) 上，x_i 与 y_i 可比
所有 i ∈ App(x) 上，x_i ≥_i y_i
存在 j ∈ App(x)，x_j >_j y_j
```

关键规则：

> **已知不可比不是忽略，而是阻止整个支配关系成立。**

不同适用性类别之间默认不可比。

由此：

```text
≻_ω 是严格偏序
```

前提是：

```text
每个维度内部是严格偏序
所有共同适用维度必须可比
不可比阻止整个支配
```

### 3.7 允许补全集合 Ω

```text
Ω_n = {ω | ω ⊨ E_n}
```

其中 `E_n` 是当前证据约束集合，必须包含：

```text
已知值保持不变
已知不可比关系保持
未知值只在允许域内补全
不适用维度不能被赋值
已知变量约束保持
```

并要求：

```text
Ω_n ≠ ∅
```

如果为空，应报告证据/约束冲突，停止前沿计算。

不能为了得到结果而擅自放宽约束。

### 3.8 三层极大集

对每个允许补全 `ω`：

```text
M(ω) = Max(F_n, ≻_ω)
```

稳健支配：

```text
x ≻_R y ⇔ ∀ω ∈ Ω_n, x ≻_ω y
```

三层：

```text
M_R = {x ∈ F_n | 不存在 y，使 y ≻_R x}
M_P = ⋃_{ω ∈ Ω_n} M(ω)
M_N = ⋂_{ω ∈ Ω_n} M(ω)
```

含义：

```text
M_R：没有被一个固定方案稳健支配
M_P：至少在一种允许补全下是极大元
M_N：在所有允许补全下都是极大元
```

命名建议：

```text
M_R：稳健极大集
M_P：可能极大集
M_N：必然极大集
```

避免“最大集”一词，因为它容易与 greatest element 混淆。

### 3.9 三层包含定理

假设：

```text
F_n 有限且非空
Ω_n 非空
每个 ≻_ω 是严格偏序
```

则：

```text
M_N ⊆ M_P ⊆ M_R ⊆ F_n
```

并且：

```text
M_R ≠ ∅
M_P ≠ ∅
M_N 可以为 ∅
```

证明：

```text
M_N ⊆ M_P：
  M_N = ∩ M(ω) ⊆ ∪ M(ω) = M_P
  因为 Ω_n 非空。

M_P ⊆ M_R：
  若 x ∈ M_P，存在 ω0 使 x ∈ M(ω0)。
  若存在 y ≻_R x，则对所有 ω，特别 ω0，y ≻_ω0 x。
  这与 x 在 ω0 下是极大元矛盾。
  所以 x ∈ M_R。

M_R ⊆ F_n：
  由定义直接成立。
```

严格偏序的交集仍是严格偏序，因此 `≻_R` 是严格偏序。  
有限非空 `F_n` 上存在稳健极大元，所以 `M_R ≠ ∅`。

每个 `M(ω)` 非空且 `Ω_n` 非空，所以 `M_P ≠ ∅`。

`M_N` 可以为空，这是合法的。

### 3.10 主体选择对应

```text
α : (F_n, S_n^att, S_n^sem, q_n) → 2^{F_n} \ {∅}
```

实际选择：

```text
d_n ∈ α(F_n, S_n^att, S_n^sem, q_n)
```

关键：

```text
α 不要求属于 M_R / M_P / M_N
```

所以主体可以选择被 Pareto 支配的方案。

但必须明确：

> **α 只是选择接口，不是对选择机制的解释。**

它允许主体选择非极大元，但不证明现实中主体具有自主性。

### 3.11 策略状态与行为

```text
B_n：实际观察到的行为
S_n^sem：主体对自身偏好、认识和关切的理解
S_n^att：主体认可并采用的注意力策略
α：给定状态下的选择对应
```

不能从行为频率直接推出 `S_att`：

```text
连续探索 ≠ 已形成探索策略
自述喜欢探索 ≠ 已采用探索策略
```

策略更新：

```text
S_{n+1}^att =
  Apply(S_n^att, ΔS_n^att)   若主体明确提交且事务成功
  S_n^att                    其他情况
```

宿主可以验证格式、版本、权限，但不能自行决定主体是否接受。

## 4. 有限模型验证

### 4.1 实验 A：偏序与三层极大集

基础定义：

```text
三个候选 a,b,c
一维严格全序的六种排列
63 个非空允许补全集合
```

结果：

```text
63/63 三层包含关系成立
63/63 M_R 非空
63/63 M_P 非空
M_N 在 54 种情况下为空，在 9 种情况下非空
```

边界案例：

```text
A1：M_R 严格大于 M_P
A2：M_P = F，M_N = ∅，M_R = F
A3：未知不等于最低评价
A4：已知不可比阻止整体支配
A5：适用性不同不建立跨类支配
```

A1 的示意：

```text
ω1: b > a > c
ω2: c > a > b
```

结果：

```text
M(ω1) = {b}
M(ω2) = {c}
M_P = {b,c}
M_N = ∅
M_R = {a,b,c}
```

A 在两个补全下分别被 B、C 支配，  
但不存在一个固定方案在所有补全下支配 A。

A2 说明：

```text
M_P = F 不一定错误
它可能只说明当前证据不足以排除任何方案
```

A3 说明：

```text
未知不会自动导致淘汰
但若 Ω 收缩到单一补全，未知也可以被确定并参与支配
```

A4 说明：

```text
一个维度不可比，整体支配不成立
```

A5 说明：

```text
不同适用性类别之间不建立支配
```

限制：

> 以上穷举覆盖三候选、一维严格全序；多维偏序的普遍性质由证明与边界案例补充，不声称穷举所有偏序结构。

### 4.2 实验 B：工作台与状态转移

设置：

```text
W_n = {a,b}
C_n = {a,b,c}
```

旧材料 a、b 分别有：

```text
保留
暂缓
Drop
```

三种去向。

新材料 c 有两种：

```text
加入
不加入
```

结构性配置数：

```text
3^2 × 2 = 18
```

检查结果：

```text
18/18 可明确表达
无状态转移冲突
Drop / Defer / Keep / Clear 可区分
Clear 与 Defer 全部材料不同
Inspect 不修改 W
Df 生命周期独立于 W
```

典型转移：

| 操作 | A | Δ | 结果 |
|---|---|---|---|
| Keep | {a,b} | ∅ | 保持 |
| Clear | ∅ | ∅ | 清空，无恢复记录 |
| Drop a | {b} | ∅ | a 退出，无恢复记录 |
| Defer a | {b} | {a} | a 退出，有恢复记录 |
| Defer a,b | ∅ | {a,b} | 两份分别暂缓 |
| Attend c + Defer a | {b,c} | {a} | 加入 c，暂缓 a |
| Attend c | {c} | ∅ | 旧材料 Drop，c 驻留 |

限制：

> 当前 `F` 只检查本轮成本；`Defer` 的未来恢复成本不保证已被预留。  
> 因此 P1 只能声明“当前轮可行”，不能声明“未来恢复一定可行”。

### 4.3 实验 C：策略敏感性、修改与保持

固定：

```text
S^sem = S0
q = q0
```

两个策略实例：

```text
S_T：任务导向
S_E：探索导向
```

计划：

```text
d_T = ({a,b}, ∅)
d_E = ({b,c}, ∅)
d_K = ({b}, ∅)
```

三者均满足资源约束，前两个材料数量与切换成本相同。

#### C1：策略接口可表达性

见证：

```text
α(F,S_T,S0,q0) = {d_T}
α(F,S_E,S0,q0) = {d_E}
```

结论：

```text
选择接口可以依赖 S_att
```

但这不是“策略敏感性机制”：

```text
α 是任意选择对应
两组函数值可以直接定义
```

所以 C1 只能证明**接口可表达性**，不能证明固定机制下的敏感性。

#### C2：自主策略修改

状态转移表：

```text
没有提出修改 → S_T
创建修改提案 → S_T
提案等待处理 → S_T
主体接受并提交 → S_E
主体拒绝 → S_T
提交失败 → S_T
```

宿主可以验证提案格式、版本和权限，但不能自行决定主体是否接受。

结论：

```text
状态转移契约允许主体提出、接受、拒绝和失败回退
```

但不证明主体能够自主形成策略。

#### C3：策略保持

初始：

```text
S_0^att = S_T
```

情况：

```text
主体明确保持 → S_T
主体拒绝修改 → S_T
多次探索行为 → S_T
宿主维护操作 → S_T
新材料进入候选 → S_T
主体后来明确接受 → 按新提案更新
```

不变量：

```text
没有有效的主体策略修改提交
⇒ S_{n+1}^att = S_n^att
```

关键区分：

```text
B_n ≠ S_n^att
```

行为变化不等于策略变化；策略保持不等于行为保持。

限制：

```text
尚未覆盖重启恢复和宿主显式写入尝试
这两项是后续状态保持测试必须补的
```

## 5. 证据等级

| 内容 | 等级 | 说明 |
|---|---|---|
| 三层包含关系 | 已证明 | 依赖 F 有限非空、Ω 非空、每个 ≻ 为严格偏序 |

## 8. 下一步：算法设计

数学已经足够设计一个**算法骨架**，但不足以解决 `α` 的内部策略。

建议算法分层：

```text
外层：
  事件接收
  候选生成
  可行计划枚举
  多维评价与 unknown/NA
  三层极大集计算
  主体选择接口 α
  Episode / Impression / BCRZ 更新
  Df / Inspect / 审计 / 持久化

内层：
  α 的第一版策略
```

α 的第一版可以是：

```text
规则型：任务优先 + 关切 + 探索预算
模型型：宿主提供可行计划与维度，模型从中选择
混合型：宿主过滤可行集，主体做选择
```

但必须明确：

> **α 是可替换组件，不是已经被数学解决的统觉核心。**

建议下一步：

```text
1. 写算法骨架规格
2. 固定 α 的第一版策略
3. 用合成连续场景验证
4. 不把“表达能力”当成“真实自主性”
```
