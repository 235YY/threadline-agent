# 可选环境集成

|环境|包内内容|另行需要|默认情况|
|---|---|---|---|
|核心宿主|Node服务、连续状态、合成测试|Node >=26.8.0|可离线运行|
|情感引擎|固定MIT源码、Python JSONL Worker|Python >=3.10|关闭；可显式启用|
|真实模型|传输、预算、一次格式恢复|运营方自己的密钥、费率核验与费用授权|关闭|
|QQ|OneBot寻址、接收去重、显式工具和回执|OneBot/SnowLuma、SDK、账号配置|未连接|
|网页/视频/语音|适配入口与现有可读能力代码|经审查的可选适配器与依赖|不保证可用|
|Office|受权调用入口|运营方自己的工作区服务、令牌与目录边界|未连接|
|Minecraft/桌面|显式可选适配入口|独立安装的本地执行器、指定世界/目录|未连接|

QQ_SDK_MODULE可指向自行安装的SDK模块，SNOWLUMA_HOME指向自己的账号配置；不从包中取得任何登录会话。JY_LEGACY_BRIDGE_ROOT可显式指定运营方审查过的外部适配层，Minecraft另支持JY_MINECRAFT_ADAPTER_ROOT与JY_MINECRAFT_STATE。这些不是自动授权。

视频模块明确区分标题/简介/字幕与真正的视频画面理解，没有接入的视觉能力不能伪装成功。Office不能继承发布者的Harness、OAuth或个人文件访问权。新用户必须配置自己的服务和目录。

本导出没有实现V15全环境开放，也没有启用全部QQ好友/群、主动联系、Office写权限或Minecraft世界修改。不能把本地通过的合成边界测试写成真实环境验收。

## 私人物品扩展

冻结源中的项链状态机依赖未随冻结包提供的相册、信箱与私人外观资源。公开框架不分发这组不完整的私人物品实现；保留显式 `NECKLACE_ADAPTER_MODULE` 接入边界。未配置时仅报告 unavailable，不创建物品数据库、不生成赠送经历、不返回虚假图片。

视频源中的默认抓取文件未包含于原冻结包。框架保留可注入 fetchText/fetchImage 的视频解析类；默认入口需要经审查的 JY_VIDEO_FETCH_MODULE（导出 safeFetch/safeFetchBuffer），未配置即明确拒绝，不启用无边界抓取。历史一次性补丁模板也不属于可运行分发范围。
