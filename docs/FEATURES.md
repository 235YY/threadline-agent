## 1. 工作台与常用设置

| 功能 | 用法与边界 |
| --- | --- |
| 本地启动 | Windows 使用 `Start-Threadline.cmd`；通用入口 `npm start`。工作台绑定本机回环和临时端口。 |
| 聊天 | 输入文本，与自己的主体交流。工作台默认离线，真实聊天需启用 DeepSeek。一轮也可能等待或不发言。 |
| 玻璃箱 | 采纳的决定、相关记忆交付量、模型声明使用的材料数和主体近况。界面展示公开决定、摘要及运行记录。 |
| 独立视图 | 情绪与需求、目标与注意力、睡前手账和好奇种子、沙盒书桌文件预览。 |
| 桌角小夜灯 | 将陪伴页面缩成简洁的展示模式。 |
| 人设 | 文本或 TXT / Markdown 导入；支持「桌边小伴侣」「好奇观察员」模板。最多 4,000 字符。 |
| 语言包 | 独立设置口吻与表达方式，可粘贴或导入 TXT / Markdown，最多 16,000 字符。宿主还提供语言包状态、版本与管理接口。 |
| 模型 | DeepSeek Key、余额接口凭据检查、在线开关、`off / low / high` 思考强度、本地每日额度。工作台重启后重新输入 Key。 |
| 手动主动认知 | 「自主活动一步」可推进一个待办任务，或给主体一次自主选择机会；「让它想一会儿」发起反思。需在线和有额度。 |
| 手动整理 | 「立刻做一次梦」运行慢脑。离线时可生成手账；待整理游标保留给之后的在线整理。 |
| QQ 连接管理 | 配置后启动或断开连接器，显示连接状态；连接前需完成账号登录与 SDK 安装。 |
| 日常安全 | 本地工作台启动有随机入口地址、本机来源校验和网页内容安全策略；运行资料在 `_local/desktop`。 |

## 2. 认知、状态和任务

| 能力 | 功能与使用条件 |
| --- | --- |
| 事件流与来源 | 外界消息和工具反馈进入 Subject Inbox，保留来源、会话、对端与时间。事件流保留同流、兄弟流与他处关系；跨会话提示与当前正文有各自范围。 |
| 连续认知 | ContinuitySession 组装当前事件、已交付材料、过往状态、注意力和未完成过程。一般回合、反思、工具回执后续及任务入口按各入口权限推进。 |
| 统觉与主观领域 | 统觉承接外部材料和内部状态，保留自我、关系、世界和规范等认识领域的可选接线。工作台启用统觉与主体领域；标准宿主按开关。 |
| BCRZ 主观状态 | 有版本的认识、关切、条件判断与行动准备。可在后续认知继续使用；变更须提交已读版本与有效依据。 |
| Impression 主观印象 | 主观记忆 V2 保留印象及其后续修订。工作台启用 V2，普通回复可顺手用精简便签留下有意义的内容。形成、持久化、后续交付与实际使用各有证据。 |
| 注意力与材料工作台 | 焦点、前台材料、驻留用途、未决问题、待接续动作和多个 Process。材料可展开、退出或显式查回，结束一个用途后保留其他用途仍需要的共享材料。 |
| Process | 承载连续工作与调查。主体可在已有授权与已交付对象范围内建立或撤回 Event–Process 显式关联。Event 引用固定版本，Process 具有稳定身份；关联历史保留。 |
| Intent | 主体可以提出、推进、等待或结束目标。目标可跨轮次持久化；AgentTask 结束后由主体判断原目标是否完成。 |
| Decision | 主体给出公开选择及依据。程序校验对象版本、引用和权限，再原子提交相关改变。主体可以选择回复、查阅、操作、等待或沉默。 |
| AgentTask | 支持多步推进、工具调用、保持结果、暂停、重规划、转向、求助、等待和终止。工作台由「长链执行能力」控制创建及部分生命周期操作。 |
| Task 与 Process | 主体可明确选择这一轮交付的 Process，也可留空。任务起始、观察和可验证结果可进入归属历史。Intent、Process、线程和来源会话分别保存。 |
| 自主节律 | 可在空闲时给主体反思、决定与执行下一步的机会，也可继续已有任务。工作台默认未开启后台自主节律；标准宿主需要心跳和自主开关。保持等待是合法选择。 |
| 夜间与主动联系 | 默认夜间窗口抑制定时新唤醒，仍处理入站。已授权的主动私聊另外受接收对象、理由、冷却、免打扰、未回复次数和重复依据检查；具体约束随宿主策略。 |
| 结果回流 | 将任务观察、真实工具回执、已知失败和未知结果送回后续认知。投递、采用、执行和送达分别记录。 |
| 精简协议 | 工作台使用 `intent-v1`。模型用短句柄选对象、表达操作，宿主编译为标准事务。未交付材料的引用会被拒绝。 |
| 失败反馈 | 参数、权限、版本和证据错误返回具体拒绝。满足条件的机械格式错误最多进行一次纠错，原始公开输出和请求费用仍保留。未知执行结果不自动重发。 |

| --- | --- |
| Event 事件底片 | 保存实际观察、报告和回执。工作台的退役操作影响可用状态，原事实和历史证据保留。 |

| 整库混合查找 | 在整个获准记忆库召回，结合关键词／BM25、主题线索、人物与 Process、知识图谱的有限扩散，可加 E5 向量召回和 BGE 重排。上下文和实际受众共同约束结果。 |

| 主动检索 | 主体可按人物、会话、过程、依据、进展和关系找材料，也可翻页或展开正文。摘要、正式交付与可引用材料分别处理。 |
| 图谱和版本 | 在现有记录上投影支持、反例和关联边，保留固定版本；过期、冲突和依据变化可回溯。图谱不会自行决定主体应接受的认识。 |
| 私聊材料治理 | 检查场景、受众、证据来源和时效；不同联系人的私聊不会仅因关键词相似而互相交付，群聊材料另受范围规则。 |
| 慢脑 A 轨 | 按持久化游标整理新材料；原子事实提取、时间归一、逐条召回，然后选择保留、添加、补充、替代或绑定关系。以来源校验、近重复过滤和旧文保全保护落盘。 |
| 慢脑 B 轨 | 有条件地暂停低置信、孤立的旧碎片；从跨天且有多个独立根源的材料提炼较稳定经验／倾向。依赖失效时进入复核；不会把一次经历直接晋升为长期规律。 |
| 手账与记忆地图 | 慢脑可写本地手账、好奇种子和四块速写本，包括关于你、近期大事、自我与边界、记忆地图。慢脑生成正文按本地范围交付。 |
| Auto-Dream | 在线工作台默认勾选。每五分钟查看夜间窗口与至少四条新事件；跨午夜按同一晚计数，每晚最多一次。服从预算、并发和请求防重。无界面宿主可按同一规则单独接入。 |
| P3 客观经验 | 现有条件统计与学习实验记录行动、条件和观察结果，形成计数或结果分布。和主体自己写下、采用、修订的经验分别评估。 |
| Experience Learning V1 | 可选实验，允许主体从证据提出经验，记录适用条件、实际使用和版本化修订。默认关闭；模型能否迁移经验要用真实使用评估。 |
| 调查连续性 V1 | 与 Process、工作集及历史认识接续有关的可选实验。默认关闭，独立于普通历史记录和任务接续。 |

### 可选本地检索模型

E5 把材料和查询转成向量，以补充同义词和改写表达的召回。BGE 按「查询—材料」成对打分，最多重排 8 份已授权候选。它们在本地 CPU 上运行。慢脑中的事实整理与普通聊天仍由接入的语言模型处理。

| 变量 | 填写内容 |
| --- | --- |
| `BRAIN_MEMORY_MODEL_DIR` | 本地多语言 E5 模型目录，需 tokenizer 与 `onnx/model_int8.onnx`。 |
| `BRAIN_MEMORY_RUNTIME_MODULE` | 本机已准备的 Transformers.js Node ESM 入口，例如 `dist/transformers.node.mjs`。须与 E5 路径同时提供。 |
| `BRAIN_MEMORY_RERANKER_DIR` | 可选 BGE 目录，需 tokenizer、模型配置和 `onnx/model_quantized.onnx`。 |

已核验的组合为 `Xenova/multilingual-e5-small`、`Xenova/bge-reranker-base` 和 Transformers.js 3.8.1。启动工作台前在自己的启动环境设置，也可写入标准服务的 `.env`。模型依赖和权重单独准备。向量缓存是可重建的派生数据；载入失败、超时或未配置时仍可使用关键词与关系检索。

| 能力 | 功能与使用条件 |
| --- | --- |

| 统觉联动 | 启用联动后，情绪与需求参与上下文装配，主体根据真实经历进行判断。体感、时间感与空闲线索可用自然语言表达供模型参考。 |
| DIY 配方 | 温和陪伴、好奇探索、冷静观察。还可调情绪反应、四项需要强度、疲劳恢复、心境回落、基线适应、恢复力和昼夜节律。 |

### QQ 与高级宿主

- **公开工作台**提供获准账号的一对一文字收发，默认没有连接器。需要 SnowLuma／OneBot 已启动并登录，配置实际 Bot 与对端、SDK 和账号目录。
- **标准宿主**支持来源寻址、连接器实例锁、接收去重、按策略补投、静音与唤醒、OneBot 真实回执、未知发送隔离。指定群、读取和外发范围分别配置；群接收策略可按全部、@ 或关键词区分。
- **Open Life**是高级接入方式。需显式接通策略、账号、工作区和适配器，按当前条件授予能力。仅设 `JY_OPEN_LIFE=1` 不足以完成接线。公开网页、群聊、写入、游戏分别有边界。

### 标准宿主功能开关

这里的默认值针对标准无界面入口。工作台会预设精简协议、统觉、主体领域、主观记忆 V2 和任务历史。

| 开关 | 控制内容 |
| --- | --- |
| `JY_INTENT_PROTOCOL` | 精简模型协议 |
| `JY_AFFECT`、`JY_AFFECT_FUSION` | 启用 Limbic、接入统觉。联动需要先启用引擎 |
| `JY_APPERCEPTION_V1`、`JY_SUBJECTIVE_DOMAINS` | 统觉和主观领域 |

| `JY_ANCHOR_DIRECTORY`、`JY_MEMORY_SCOPE_V1` | 锚点目录和 V1 记忆范围优化。推荐流程仍有自身的受众检查 |
| `JY_INVESTIGATION_CONTINUITY_V1`、`JY_EXPERIENCE_LEARNING_V1`、`JY_ALGORITHM_V011` | 调查连续性、主体经验学习、算法 V0.11 兼容分支。默认都关闭 |

## 6. 数据、费用、运行与诊断

| 项目 | 行为 |
| --- | --- |
| SQLite 存储 | 同一个主体库保存事实、版本、引用、状态与运行必要记录。工作台使用自己的 `_local/desktop`。 |
| 运行身份 | 标准入口 `node tools/brain-service/run.mjs`；默认离线。已授权联机用 `node --env-file=.env tools/brain-service/run.mjs`；先核实数据路径。实例锁与源码指纹用于核验运行归属。 |
| 观察和调试 | `doctor.mjs` 启动前只读检查；`status.mjs` 查询运行及额度状态；另有工作台玻璃箱、持久化回执、输入包和有界调试记录。 |
| 工作台费用 | 默认 5 元/日额度设定，可编辑为 0.1–20 元。按此工作台实际请求记录及待确认的预估金额准入；不会统计账号下的其他应用。 |
| 标准宿主官方额度 | 使用对应 API Key 标签、北京时间当日、CNY 的官方上报，快照有效 90 秒，显示 5 元即停止新增。服务端账单可能延迟；报告应与实际时区匹配。 |
| 可选账本估算 | 经明确启用的宿主可以使用既有 RequestJournal 作为备用依据。该数值是本机估算，具体授权和风险由运营者掌握。 |
| RequestJournal | 持久记录模型请求身份、来源、已送达事实、费用、公开输出和未决状态。换请求 ID、改变时钟或重启都不能让同来源的未知调用自动重发。 |
| 格式与异常 | 非法建议拒绝采用，语义与权限错误交给主体处理；符合条件的格式问题可受控恢复一次。单笔失败和未知保留原事实，无关消息仍可推进。 |
| 迁移与备份 | 使用已核验的一致性 SQLite 备份或正常停机后备份原资料。标准宿主账号和密钥分开保管，旧 DailyBudgetLedger 和当前 RequestJournal 分别保留。 |
| 隐私与发布 | 发行包只包含公开源码、模板和测试。自己的数据库、聊天、记忆、头像与语音、SDK 登录材料、账本和凭据应私存。使用在线模型和外部工具时，按所授权的入口传递相应材料。 |
| 研究与测试 | `npm test` 运行公开默认测试，范围由 `scripts/current-test-files.json` 决定。附带事件、连续认知、工作台、记忆图谱、学习、恢复等示例和专项测试。私人旧反例回放独立于公开回归，默认发行不携带原夹具。 |

该冻结源码已有 **1,245/1,245** 项默认离线回归记录。完整复测使用 Node 26.12.1 和隔离的 Windows Python 3.13.9 验证环境；部分测试会检查已验证的包内 Python 路径与来源记录。源码包未附解释器，也未附运行数据。日常工作台不需要这套测试环境。外部平台、模型是否采用建议、任务是否真正执行、实际接收方是否收到、以及长期认知能力，各以对应运行回执和真实行为验收。
