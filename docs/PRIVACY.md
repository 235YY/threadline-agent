# 隐私与分发边界

发布目录采用源码白名单，不从生产目录整体打包。没有附带运行数据库、WAL/SHM、聊天、身份/关系材料、人格或风格包、截图、语音、模型请求/响应、费用账本、操作日志、DPAPI材料、令牌或账号配置。.git历史不包含在源码ZIP中。

源码中的私有账号示例已经替换为合成占位值。原始私人实验夹具不公开；对应必要回归使用合成反例。公开测试中的文字和临时状态不代表真实主体的经历。

首次启动创建的是空状态，不会自动迁移旧数据库。生产数据与公开框架没有共享写入路径。仓库中的MIT版权署名和第三方作者声明是公开许可归属，予以保留。

新运营者应自行检查自己的Git提交署名、环境文件、日志与工具输出。不要提交生成的_local、evaluation、SQLite、密钥或聊天导出。仅有.gitignore不足以证明没有泄露，应同时检查实际待发布文件清单。
