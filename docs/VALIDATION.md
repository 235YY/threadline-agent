它验证结构边界，不声称重现原私人经历。

## 独立私人原始回放

运行npm run test:private-history，或node --test test/private/investigation-history.test.mjs。
由持有人在本地显式设置JY_PRIVATE_REPLAY_ROOT，指向已封存的原始反例目录。
未配置时明确失败，不自动寻找个人目录、下载档案或跳过测试。
原请求、响应和SQLite不公开，不纳入公共默认回归或Git清单。

专项验证原三个文件固定SHA、无WAL/SHM的封存快照、仅在独占新副本初始化Store、
原输出在旧提交路径中的拒绝，以及规范化后与原对象只差精确可选null。
原文和诊断仍有对应断言；结束后再次核验原文件散列。
它保留历史反例价值，不重发原请求、不调用模型，也不冒充当前真实认知能力。
