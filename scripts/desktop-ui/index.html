    新手教程（随时点左侧「新手教程」重看）

    什么是 API Key（大脑钥匙）？
    把它想成一张“按次扣费的电话卡”。你只需要去 DeepSeek 官网（platform.deepseek.com）注册、充 5 块钱、点「创建 API Key」，复制那串 sk- 开头的字符贴进本软件就行。

    会不会偷偷扣我很多钱？
    不会！软件默认把每天上限锁在 5 元（你还能拉低到 0.5 元），而且你的钥匙只存在当前内存里，绝不会上传给任何第三方。

    1. 点左侧「外观与设置 → 大脑与性格」，贴上你的 API Key，点「一键测通 Key」。
    2. 打开「启用在线真实大脑」开关，点右上角「保存全部更改」。
    3. 回到「对话房间」就能开始聊天；点顶部「玻璃箱」按钮可以随时偷看 TA 的思考和情绪。

    顶部一键换三大界面：喜欢极简点「通用 · GPT风」，喜欢出片点「画报 · 小红书风」，喜欢专业工作台点「极客 · VSCode风」。

    随便塞任何形象：在「外观与设置 → 外观工坊」上传头像、半身立绘、背景图，或者拖入 DSH 的 pet.json 桌宠包。

    点左侧「一键连接」，看到 4 张大卡片（会说话的数字人 / Cortico 桌宠 / AstrBot 机器人 / DSH）——直接点你想接的那张卡，系统会自动帮你打开通道并配好参数，照着弹出的 1、2、3 步点复制粘贴就行，完全不用写代码。

    Q：聊久了会占满硬盘吗？
    A：不会，内置无损压缩和每日自动清理，所有记忆和聊天事件永远不会被自动删掉。

    Q：怎么知道有没有新版本？
    A：点左侧「检查更新」即可检测最新版并查看更新说明。
